# 프로젝트 설계 과정

## <26.11.11>

1. shell이란 무엇인가?
    1. user와 os(kernel) 사이에서 명령/명령결과를 전달하는 인터페이스
    2. os의 기능과 자원에 접근하고 이를 제어할 수 있도록 지원함

2. 동작방식의 이해
    1. user의 명령어 입력
    2. 명령어 해석(parsing)을 통한 명령어와 옵션, ipc 기능 등을 분류
    3. 명령어를 수행
    4. 수행한 결과를 출력(stdout이 될 수도 있고, 또 다른 파일에 쓰게 될 수도 있다)

3. 얼마나 구현할 것인가
    1. gui는 특별히 만들지 않고, 터미널에서 while문으로 구현하면 될 것 같음
    2. 단순 명령어 구현
        - 인자가 필요없는 명령어
        - 인자가 필요한 명령어
            - 단일 인자
            - 여러개의 인자(붙여서? 따로?)
    3. 리다이렉션 기능, 명령어 간 파이프 기능

4. 어떻게 구현할 것인가
    1. 명령어를 외부/내부(built-in) 명령어로 나누어 처리
    2. 외부 명령어는 fork로 처리
